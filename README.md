# RegTech Analytics Dashboard | Tableau

An interactive **RegTech Analytics Dashboard** built in Tableau to provide a centralized view of regulatory intelligence, compliance operations, workflow performance, and U.S. state-level regulatory activity.

The project is designed from an executive and business-user perspective, enabling stakeholders to monitor key KPIs, identify compliance risks, analyze regulatory trends, and drill into operational performance.

---

## Objective
The primary objective of this project is to demonstrate how Tableau can transform complex regulatory and operational data into an interactive, executive-ready analytics solution that supports compliance monitoring, operational analysis, and data-driven decision-making.

## Project Overview

The dashboard consists of **four analytical views**:

### 1. Executive Overview
Provides a high-level view of overall platform performance and regulatory activity.

**Key Metrics:**
- Total Queries
- SLA Rate
- Task Completion
- Active Institutions
- Revenue / ARR
- Regulatory Activity
- Query Trends

**Key Visualizations:**
- KPI Cards
- Query Trends
- Institution Performance
- Subscription Tier Analysis
- Compliance Area Analysis

---

### 2. Regulatory Intelligence

Provides insights into regulatory changes, amendments, agencies, and law-family trends.

**Key Metrics:**
- Total Regulations
- Amendments
- Pending Effective Regulations
- Agencies Covered
- Average Citation Depth

**Key Visualizations:**
- Regulatory Amendments by Quarter
- Regulatory Events by Agency
- Event Type Breakdown
- Regulatory Content Growth by Law Family
- Recent High-Impact Regulatory Events
- Upcoming Effective Dates

---

### 3. Operations Dashboard

Monitors workflow execution, task performance, SLA compliance, and operational efficiency.

**Key Metrics:**
- Total Workflow Tasks
- Task Completion Rate
- SLA Rate
- Overdue Tasks
- Legal Reviews
- Average Days to Complete

**Key Visualizations:**
- Workflow Task Status
- Task Priority Breakdown
- Tasks by Compliance Area
- SLA Breaches by Compliance Area
- Institution Operations Summary
- Query Channel Distribution

---

### 4. State Coverage

Provides geographic and state-level analysis of regulatory activity and operational performance across the U.S.

**Key Metrics:**
- States Covered
- Federal Agencies
- State Query Volume
- Average State SLA
- Top State by Queries
- Query Growth

**Key Visualizations:**
- U.S. State Query Heat Map
- Federal Agency Distribution
- State Performance Matrix
- Bottom 15 States by SLA
- Regional Query Volume
- Impact Level by Quarter

## 📈 Business Use Cases

The dashboard helps users:

- Monitor regulatory activity across jurisdictions.
- Identify high-impact regulatory changes.
- Track amendments and upcoming effective dates.
- Monitor workflow completion and SLA performance.
- Identify areas with high SLA breach volumes.
- Compare state-level regulatory activity.
- Analyze federal agency query distribution.
- Identify operational trends and potential compliance risks.
- Support data-driven compliance and operational decisions.
